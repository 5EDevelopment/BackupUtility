# BackupUtility
All-in-one preparation suite before formating an Windows OS
======================================================================
PROJECT TITLE: 5ED Backup Utility for Windows
TYPE: Windows Console Application (.exe)
VERSION: 1.0.0
======================================================================

1. ABOUT THE TOOL
----------------------------------------------------------------------
An all-in-one preparation suite designed to run before formatting, 
staging, or clean-installing an operating system. This utility 
automates critical data preservation tasks through a simple 
command-line menu interface.

2. KEY FEATURES
----------------------------------------------------------------------
- Custom User Files Backup: Safeguard personal documents and data.
- Driver Management: Export, backup, and restore system drivers.
- Windows Activation: View, backup, and restore your license keys.
- Full System Image: Create a comprehensive backup of the OS state.
- 3-in-1 Toolkit: A bundled pre-reinstall bundle for speed.

3. SYSTEM REQUIREMENTS & PRIVILEGES
----------------------------------------------------------------------
- OS: Windows 10 / Windows 11
- Requirements: Must be executed with Administrative Privileges.
                (Right-click -> "Run as administrator")

4. HOW TO USE
----------------------------------------------------------------------
1. Double-click the compiled .exe file.
2. Ensure the terminal window displays "Administrator:" in the title.
3. Type a number from 1 to 9 corresponding to your desired action.
4. Press [ENTER] to execute the selected backup module.
5. Follow any on-screen prompts or folder path destinations.

5. IMPORTANT NOTES
----------------------------------------------------------------------
- Antivirus Warning: Because this tool is compiled from a .bat file 
  into an .exe, some antivirus scanners may trigger a false positive. 
  You may need to whitelist the executable if it gets blocked.
- Storage: Ensure your target backup drive has sufficient space 
  before initiating full system images or user file backups.
